雙人對戰射擊遊戲

這是一款使用 Pygame 與 Tiled Map (pytmx) 製作的雙人對戰射擊遊戲。

玩家將在地圖中操控角色，透過射擊、閃避與撿取隨機出現的寶箱獲得 buff 來對抗對手。


1. 遊戲介紹

雙人對戰：支援 2 名玩家在同一台電腦對戰。

寶箱 & Buff 機制：隨機生成的寶箱可被射擊破壞，掉落的 buff 提升角色能力：

⚡ lightning：增加移動速度

🗡 sword：增加攻擊傷害

🛡 shield：回復血量

復活機制：玩家最多有 3 條命，每次死亡有 5 秒倒數復活。

地圖碰撞：使用 Tiled 編輯地圖，玩家與牆壁、寶箱有完整的碰撞偵測。

勝負判定：當其中一方用完所有生命時，遊戲結束並顯示勝敗畫面。


2. 操作方式

玩家 A

移動：WASD

射擊：I (上) J (左) K (下) L (右)

玩家 B

移動：方向鍵 ↑ ↓ ← →

射擊：數字小鍵盤 8 (上) 4 (左) 2 (下) 6 (右)

ESC：離開遊戲

任意鍵：開始遊戲或重新開始
